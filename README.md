# Divya Balraj — Personal Portfolio Website

A modern, responsive, and beautifully designed personal portfolio website showcasing web development projects, technical skills, and background.

![Portfolio Preview](assets/images/profile-new.png)

## 🌟 Overview

This portfolio is built using modern semantic HTML5, CSS3, and JavaScript. It features clean typography using Google Fonts (**Space Grotesk** for headings and **Inter** for body text), smooth scroll reveals, interactive project previews, and full responsive design across desktop, tablet, and mobile devices.

### 📄 Pages & Architecture
- **[Home (`index.html` / `home.html`)](index.html)**: Hero section with animated introduction, subtitle typewriter effect, and quick navigation.
- **[About (`about.html`)](about.html)**: Personal background, education, philosophy, and interactive stats.
- **[Skills (`skills.html`)](skills.html)**: Technical proficiency in Frontend (HTML5, CSS3, JavaScript, jQuery, Bootstrap), Development Tools, and Core CS competencies.
- **[Projects (`projects.html`)](projects.html)**: Featured showcase of interactive web applications with live demo links and feature highlights.
- **[Contact (`contact.html`)](contact.html)**: Contact cards, direct email/phone links, location, and interactive contact message form.
- **[Single-Page Experience (`pro.html`)](pro.html)**: Unified all-in-one portfolio view with navigation anchor scrolling.

## 🚀 Featured Projects

### 1. Interactive Theme-Switching Calculator (`calproject.html`)
- **Technologies:** HTML5, CSS3, JavaScript, jQuery
- **Features:**
  - Multi-theme switcher (**Dark**, **Light**, and **Retro**)
  - Dynamic mathematical expression evaluator
  - Responsive button pad with clear (`AC`) and delete (`DEL`) functions

### 2. Trippy Experience Travel & Tourism Website (`mediaweb.html`)
- **Technologies:** HTML5, CSS3, JavaScript, jQuery, Font Awesome
- **Features:**
  - Curated holiday tour packages for global destinations (Japan, Switzerland, Maldives, Paris, Dubai, China)
  - Interactive image lightbox popup gallery
  - Hero text blur-in focus animations
  - Responsive travel booking and trip search interface

### 3. BMI Health & Fitness Calculator (`bmicalc.html`)
- **Technologies:** HTML5, CSS3, JavaScript
- **Features:**
  - Dual measurement systems: **Metric** (kg/cm) and **Imperial** (lbs/inches)
  - Pediatric and minor age verification logic
  - Real-time BMI category classification (Underweight, Healthy Weight, Overweight, Obese)
  - Standard WHO BMI reference table

## 💻 Local Development

To view and run the website locally:
1. Clone the repository:
   ```bash
   git clone https://github.com/divya2004-74/portfolio.git
   ```
2. Open `index.html` in your web browser, or serve using VS Code Live Server / Python HTTP server:
   ```bash
   python -m http.server 8000
   ```
3. Open `http://localhost:8000` in any modern web browser.
